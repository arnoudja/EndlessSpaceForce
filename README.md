# EndlessSpaceForce

Browser arcade shooter with idle credits and steampunk hangar UI. See [docs/architecture.md](docs/architecture.md).

## Dev (Omarchy / Intel)

```sh
# Terminal 1
cd backend && cargo run

# Terminal 2
cd frontend && npm install && npm run dev
```

- API: http://127.0.0.1:8787
- UI: http://127.0.0.1:5173

Environment: `ESF_LISTEN`, `ESF_DATABASE_PATH`, `VITE_API_URL`.
